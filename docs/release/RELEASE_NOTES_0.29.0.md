# Mosaic Tokenizer 0.29.0

Mosaic 0.29.0 is the final pre-1.0 contract candidate. It freezes the public C/trust declarations and the stable binary-format identities, makes shared-library exports explicit, and defines the compatibility, deprecation, and threat-model policies intended for the 1.x line. No canonical tokenizer semantics change is introduced.

The candidate contract contains 167 core public functions, 9 optional trust functions, MOSPACK v1, TokenDocument `MSTIRD01` v1, packed-model `MSTKPK01` v1, cache-record `MSCACHR1` v1, signature-record `MSSIGV01` v1, registry schema 1, and tokenizer semantics version 2.
