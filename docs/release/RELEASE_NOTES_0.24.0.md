# Mosaic Tokenizer 0.24.0

Enterprise observability release.

- privacy-preserving structured operation events;
- success/failure/resource event masks;
- per-tokenizer sequence and semantic fingerprint correlation;
- concurrent callback support through the bounded executor;
- same-tokenizer callback reentrancy suppression;
- immutable pre-seal observer configuration;
- no change to tokenizer semantic or deployment identity.
