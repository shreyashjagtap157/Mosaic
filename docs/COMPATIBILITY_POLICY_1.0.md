# Legacy compatibility-policy location

This filename is retained so historical links do not break.

The current compatibility policy is `docs/COMPATIBILITY_POLICY.md` and the canonical four-part product release scheme is defined in `docs/VERSIONING_POLICY.md`.

The former `1.x` product-label assumption was superseded on 2026-08-08 after real Windows qualification demonstrated that the product should remain in stability generation `0` until cross-platform release gates are complete. Frozen ABI, semantic, and binary-format contracts remain independently enforced and were not rolled back.
